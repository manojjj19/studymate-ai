# Sample Data Directory

This folder contains synthetic study notes for testing StudyMate AI without needing private student notes or copyrighted textbooks.

## Files
- `create_sample_pdf.py`: Script to generate a multi-page PDF covering Computer Architecture, Machine Learning, and Deep Learning.
- `sample_study_guide.pdf`: Generated synthetic study guide (run `python sample_data/create_sample_pdf.py` to create or regenerate).

## Privacy & Safety
- **No Private Data:** Never commit private student documents or personal academic transcripts to Git.
- **Copyright Free:** All sample notes are original synthetic text.
